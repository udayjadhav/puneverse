# Security

## Reporting

If you find a vulnerability in PuneVerse, open a private report with the maintainers (do not file a public issue with exploit details).

## Scope notes (Phase 1)

- No auth, no paid cloud credentials required for Option 0.
- Do not commit `.env` files or API keys.
- Large OSM extracts and PMTiles stay out of git (see `.gitignore`).
